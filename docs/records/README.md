# PDDR records

Project Design Decision Records for this repository live in this directory. Create a record from `.pddr/template.md` and validate it with `python .pddr/pddr.py validate`.

Decision status and delivery status are separate: agreement on a direction is not evidence that its implementation has been validated. Each record contains the supporting evidence and revisit conditions.
