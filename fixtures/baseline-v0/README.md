# Baseline v0 fixtures

All files in this directory are synthetic.

They freeze the intended behavior of the pre-OSS workflow without copying employer data, private project names, source code, or real session content.

## Files

- `session-metrics.json` — synthetic deterministic telemetry
- `expected-weekly.md` — expected Weekly interpretation
- `expected-monthly.html` — minimal expected Monthly presentation

The fixtures intentionally include a forked session so future lineage-aware implementations can demonstrate the difference between raw and independent recurrence counts.
